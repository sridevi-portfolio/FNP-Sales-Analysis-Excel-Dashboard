# FNP Sales Analysis - Excel Dashboard

## Overview
Analyzed 1000 orders for Ferns and Petals (FNP) to find revenue trends, top products, and customer behavior using Advanced Excel.

## Dashboard Preview
![Dashboard](Dashboard_Screenshot.png)

## Key KPIs
- **Total Orders:** 1000
- **Total Revenue:** ₹35,20,984
- **Avg Delivery Time:** 5.53 Days
- **Avg Spend:** ₹3,520.98

## Key Insights
1.  **Seasonality:** Feb (Valentine) ₹7L and Aug (Rakhi) ₹7.2L are peak months. Business is occasion-driven.
2.  **Top Product:** Magnam Set (₹1.22L) - Combo Sets sell more than single items.
3.  **Customer Behavior:** Peak ordering 6 PM - 8 PM. Best time to run ads.
4.  **Category:** Colors category leads with ₹10L revenue.
5.  **Occasion:** Anniversary is evergreen highest revenue (₹6.7L), Diwali needs improvement (₹3L).
6.  **City:** Imphal, Dhanbad, Kavali are top Tier 2/3 cities.

## Business Recommendations
- Increase ad budget in Feb & Aug by 50%
- Stock more Magnam Set & Quia Gift combos
- Run ads 6PM-8PM for max conversion
- Bundle low sellers (Mugs, Plants) with Colors

## Tools Used
Advanced Excel, Pivot Tables, VLOOKUP, Charts, Slicers, Timelines
